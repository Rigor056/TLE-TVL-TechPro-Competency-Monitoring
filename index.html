Free Online Cloud Database Setup (Supabase)

Para ma-save ang lahat ng records online at ma-access ng iba't ibang teachers/assessors kahit saan (GitHub Pages, Netlify, Vercel, o local browser), ikonekta ito sa isang 100% Free Supabase PostgreSQL Database:

  1. Gumawa ng libreng account sa supabase.com at gumawa ng New Project.
  2. Pumunta sa SQL Editor sa Supabase at i-run ang SQL code na ito para magawa ang table:
    CREATE TABLE tvl_profiles ( id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, role TEXT NOT NULL, name TEXT NOT NULL, lrn TEXT, qualification TEXT NOT NULL, grade_level TEXT, section TEXT, nc_outcome TEXT DEFAULT 'Pending', competencies JSONB NOT NULL, updated_at TIMESTAMPTZ DEFAULT NOW() ); ALTER TABLE tvl_profiles ENABLE ROW LEVEL SECURITY; CREATE POLICY "Public Access" ON tvl_profiles FOR ALL USING (true) WITH CHECK (true);
  3. Pumunta sa Project Settings -> API, at i-copy ang Project URL at anon public API Key sa ibaba:
